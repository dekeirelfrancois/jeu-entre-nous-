# Jeu Entre Nous 💞

Petite appli web pour jouer à deux le soir : Action ou Vérité, pioche de défis, dés de l'amour et roulette. 100 % locale : aucun compte, aucune donnée envoyée, tout reste sur l'appareil.

## Utilisation

1. Ouvrir `index.html` dans un navigateur (téléphone ou ordinateur).
2. Sur iPhone/Android : « Ajouter à l'écran d'accueil » pour la lancer comme une vraie appli.
3. Entrer les deux prénoms, choisir les niveaux d'intensité (Doux 😌 / Coquin 😏 / Torride 🔥) et jouer.

## Fonctionnalités

- 🎭 Action ou Vérité (roue qui tourne)
- 🃏 Pioche de défis en alternance
- 🎲 Dés de l'amour (action × zone)
- 🎡 Roulette 1-2-3 (toi / moi / nous deux)
- 🃏 1 joker chacun par soirée, gage de rattrapage si refus
- ✍️ Cartes personnalisées
- 📊 Scores et statistiques de vos soirées
